# AttributedRelationships

Demo project to explore converting a CoreData project with ordered many:many and one:many relationships into a data model compatible with CloudKit

This project was built in public by @tom_frog@mastodon.social starting in December 2025 as a way of forcing myself to actually implement cloud syncing for my ABC notation app, the Craic.  
Along the way, I've gone down various IOS development rabbit holes,  including Swift enums, JSON encoding/decoding and Swift testing.   

I have not used any AI tools in creating any of this, but I have used online resources and tutorials.  I've kept a copy of the Mastodon threads [here](./MastodonThread.md) as a way to help preserve my train of thought while building this.
